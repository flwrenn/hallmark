### Breadboard Strategy

All purchased components are SMD. For breadboard prototyping:
- **A1304 (SOT-23)** -> solder onto SOT-23 to DIP adapters + pin headers. Use 6-10 for proto, keep rest for PCB.
- **CD74HC4051M96 (SOIC-16)** -> solder onto SOIC-16 to DIP-16 adapters. Use 2-3 for proto, keep 6 for PCB.
- Start with SMD practice kit before real components.
